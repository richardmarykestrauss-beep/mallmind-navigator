## 5. Architecture outcome

The deployed `runAssistant` flow:

```text
User request
  → deterministic route preflight        (20A.5 — explicit "take me to / where is" → build_route, quota-independent)
  → deterministic shopping preflight      (20A.6D — clear product/budget/cheapest answered from MallMind data)
  → strict verified-only guard            (20A.6D.1 — "verified only" never widens to medium/low trust)
  → Gemini only when needed               (vague / mission / conversational requests)
  → Gemini failure recovery               (20A.6E — deterministic answer / verified-only guard / safe degraded message)
  → shopper-safe response
```

Doctrine preserved throughout: no fabricated price, no fabricated stock, no invented shop, no invented route,
no internal-status leakage; verified/trust language comes only from the shopper-safe trust labels; budget search
is trust-first; cheapest search is price-first with a verified alternative/warning; no route/navigate promise
unless route availability is known.

## 6. Final verdict

```text
Sprint 20A.6 — PASS
```

MallMind's **core TV and route journeys no longer depend on Gemini availability**: clear product queries
(budget / cheapest / product-search) and explicit navigation are answered deterministically from MallMind's own
data and indoor map, before Gemini is ever called — making them quota-independent and reliable under load.
The strict **verified-only** request is held to its word (no widening to lower-trust matches). Vague, conversational,
and mission-style requests **retain AI enhancement** via Gemini, and when Gemini is unavailable the assistant
**degrades safely** (deterministic answer where possible, otherwise an honest non-error message) instead of
hard-failing.
