# Sprint 19C.8B — Shopping Assistant Intelligence Engine v1

## Status

Complete.

## Purpose

Sprint 19C.8B implemented a pure Shopping Assistant Intelligence Engine for MallMind.

The goal was to make the assistant safer, more structured, and more shopper-aware without redesigning the UI or changing the retail database.

This sprint converts trusted product/shop/route data into shopper-facing recommendation logic.

## Strategic Context

Sprint 19C.7 created the Retail Intelligence Core.

Sprint 19C.8A documented the Shopping Assistant Intelligence Doctrine.

Sprint 19C.8B turns that doctrine into a testable backend intelligence layer.

MallMind is now moving from:

- generic assistant response
- scattered product recommendation logic
- implicit trust handling

toward:

- structured shopping intent
- safe shopper-facing trust labels
- ranked product options
- best option plus backup
- action-ready next steps

- publish retail data
- change review_status
- touch navigation graph files

### 2. Intent Classification Added

The engine now detects shopper intent types including:

- product_search
- budget_search
- cheapest_option
- closest_option
- best_value
- navigation_request
- mission_shopping
- unknown

Examples covered by harness:

- "I need a TV under R4000"
- "Where is Game?"
- "cheapest 43 inch TV"
- "gift under R300"

Budget extraction is supported for phrases such as:

- under R4000
- below R 3,500
- under R300

The engine does not invent budgets when no budget is present.

### 3. Shopper-Safe Trust Translation Added

The engine translates internal product/trust states into shopper-safe labels.

Examples:

- `manually_verified` → Verified option
- `verified` → Verified option
- `live_feed` → Live retailer feed
- `needs_review` → Price may need confirmation
- `demo` → Example/demo data
- unknown/missing → Not confirmed yet

The engine prevents raw internal terms from appearing in shopper messages.

Internal terms blocked from shopper messages include:

- manual_fact_entry
- csv_manual
- pending
- approved
- published
- retail_observation
- needs_review
- manually_verified
- live_feed
- data_quality_status

### 4. Product Recommendation Ranking Added

The engine ranks product candidates using multiple factors, not price alone.

Ranking considers:

- product relevance
- trust/confidence
- budget fit
- price/value
- walking effort
- shop certainty
- route availability
- open-now status where provided

Important doctrine behaviour:

A closer verified option can beat a cheaper weak-confidence option.

A cheaper verified option can win when trust and distance are similar.

### 5. Safe Answer Builder Added

The engine produces a structured shopping answer.

Output includes:

- intent
- bestOption
- backupOption
- warnings
- nextAction
- shopperMessage

The shopper message is short, decisive, and action-oriented.

It avoids inventing:

- price
- stock
- route
- availability
- verification

### 6. Assistant Integration Added

Updated:

`google-cloud-backend/src/services/geminiService.ts`

Gemini's existing free-text response remains unchanged.
