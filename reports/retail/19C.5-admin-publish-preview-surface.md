# Sprint 19C.5 — Admin Publish Preview Surface

## Status

Complete.

## Purpose

Sprint 19C.5 added a safe admin-side dry-run preview for staged retail observations before they can be published into live shopper-facing products.

This sprint protects the MallMind retail data trust layer by ensuring weak/manual observations do not accidentally become verified product prices.

## Why This Sprint Matters

MallMind's retail database must distinguish between:

- staged observations
- reviewed observations
- approved publishable observations
- live shopper-facing products
- verified evidence-backed prices
- weak/manual rows that still need review

The sprint prevents this failure mode:

> Manual CSV/admin-entered prices accidentally becoming shopper-facing "Verified price" data.

## Completed Work

### Backend

Added:

- `GET /admin/retail-observations/publish-preview`

The endpoint is:

- admin protected
- read-only
- dry-run only
- gated by `review_status = approved`
- limited to unpublished observations
- designed to mirror the controlled publisher's trust logic

The endpoint returns:

- publishable count
- warning count
- projected insert/update action
- projected product quality
- source details
- warning details

### Frontend Client

Added:

- `RetailObservationPublishPreviewItem`
- `RetailObservationPublishPreviewResponse`
- `getRetailObservationPublishPreview()`

### Admin UI

Added:

- Approved Publish Preview panel
- publishable approved row count
- preview warning count
- dry-run mode label
- refresh preview button
- preview cards for approved rows
- projected product quality labels
- row-level warning display

### Safety Fixes

Fixed:

- missing `CardDescription` import that caused admin black screen
- preview panel not mounted into Retail Review
- post-deploy CORS issue by restoring `ALLOWED_ORIGIN=*` for dev testing
- confusing Retail Review actions

Review actions are now status-aware:

- pending rows: More Info / Reject / Approve
- approved rows: Move Pending / More Info / Reject
- rejected rows: Move Pending / More Info / Approve
- needs_more_info rows: Move Pending / Reject / Approve
- published rows: locked, no review actions
